# 🚀 CreatorFlow AI — Production-Ready AI Content Engine & SaaS

CreatorFlow AI is an enterprise-grade AI content generation platform built for creators, agencies, and founders. Powered by **Next.js 14**, **Tailwind CSS**, **Google Gemini API**, and **Stripe**, it enables users to generate optimized social media copy, YouTube scripts, and marketing hooks seamlessly.

---

## ✨ Core Features & Highlights

- 🤖 **Multi-Platform AI Generation:** Instant, context-aware content generation for YouTube, LinkedIn, X (Twitter), and Instagram hooks.
- 💳 **Stripe Billing & Subscriptions:** Tiered pricing plans (Starter, Pro, Enterprise) with automated token management.
- 🔐 **Authentication:** Secure user onboarding with Clerk / Supabase supporting Email & Social OAuth.
- 📊 **Creator Dashboard:** Real-time generation metrics, content history, and token usage analytics.
- ⚡ **Optimized API Token Streaming:** High-speed generations using Google Gemini API.
- 🎨 **Modern Dark UI:** Fully responsive interface engineered with Next.js App Router and Tailwind CSS.

---

## 🛠️ Tech Stack & Architecture

- **Frontend:** Next.js 14 (App Router, TypeScript), Tailwind CSS
- **AI Model:** Google Gemini API
- **Auth:** Clerk / Supabase Auth
- **Database:** PostgreSQL / Supabase
- **Payments:** Stripe Checkout & Webhooks
